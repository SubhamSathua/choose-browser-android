Privacy Policy

Effective date: 14 November 2026  ·  Choose Browser v4.30.1

Privacy First Principle

Zero Data Collection & Zero Tracking

Choose Browser is built from the ground up on an uncompromising zero-knowledge, zero-telemetry architecture. The application does not collect, record, log, profile, sell, or transmit any personal data, clicked URLs, search queries, browsing habits, device identifiers, or analytics. Your browsing activity belongs solely to you and never leaves your device.

100% On-Device Processing

All core capabilities—including link interception, installed browser discovery, URL parameter cleaning, and offline QR code rendering—operate entirely locally inside your device's memory. Choose Browser operates without any central tracking infrastructure or cloud servers.

Link Routing & Inspection

Browser Intent Interception

Choose Browser acts as a system-wide browser router to restore your choice of web browser for every link tap on Android 11+. When a web link (HTTP/HTTPS) is tapped in any application, Choose Browser intercepts the intent, queries your locally installed web browsers via Android's package manager, and renders a lightweight overlay chooser.

  • URLs are processed ephemerally in memory solely to complete the intent handover.
  • No history of visited links, opened domains, or target apps is ever recorded or indexed.
  • Browser exclusion selections (hiding specific browsers from the chooser) are stored exclusively in private local storage on your device.

Automatic Link Sanitization (Tracker Stripping)

Choose Browser automatically strips intrusive tracking parameters (such as utm_source, utm_medium, fbclid, gclid, and referral tokens) before handing URLs to your selected browser. Sanitization is performed locally using an embedded query filter engine based on Brave Query Filter rules. URLs are never sent over the internet for analysis or cleaning.

Show Link Inspector & Editor

The Show Link tool lets you review, decode, copy, and edit raw URLs in a secure sandbox before opening them. Link inspection operates entirely in volatile memory. Choose Browser does not monitor your clipboard in the background or collect inspected links.

Offline QR Code Generation

Choose Browser includes built-in offline QR code generation for intercepted URLs, accessible via action buttons, the Full-Page QR viewer, and Chrome-style Sharesheet actions. All QR code bitmaps are rendered strictly on-device using ZXing without contacting any external API or web service.

Preview Page (Private Web Preview)

Ephemeral Sandboxed Browsing

The built-in Preview Page provides a fast, isolated web preview session. It operates with strict privacy defaults:

  • Automatic Session Wiping: All cookies, cached files, HTTP cache, and session records are erased immediately upon closing the preview.
  • No Persistent Storage: DOM storage, Web SQL, IndexedDB, password saving, and form autofill are permanently disabled.
  • Third-Party Cookie Blocking: Cross-site cookies are blocked by default.
  • Built-In Content & Ad Blocker: Built-in network-level filtering prevents connections to known analytics, tracking, and advertising hosts.
  • JavaScript Safeguards: JavaScript execution is restricted by default and only enabled on explicit toggle.
  • Security Enforcement: Strict HTTPS and SSL validation is enforced. Mixed content and insecure certificates are rejected automatically.

Third-Party Web Content Notice

When loading a website inside the Preview Page, that specific third-party site receives standard HTTP web requests and operates under its own privacy policy. Choose Browser does not monitor, inspect, or log the content of websites you browse.

Themes & Local Preferences

On-Device Storage Only

The only data stored on your device consists of non-identifying application preferences:

  • Selected color theme (Monochrome, AMOLED, Material, Catppuccin, Dracula, Cyberpunk, etc.)
  • Display theme mode (System default, Light, or Dark)
  • Browser exclusion filters and preview preference toggles
  • Update channel preference (Stable, Beta, or Alpha)

These preferences are stored in Android's sandboxed SharedPreferences and are never synchronized with any remote server or third party.

Android Permissions Rationale

Explicit & Minimal Permissions

Choose Browser requests only the permissions strictly required to perform its functions:

  • Default Browser (Intent Handling): Enables system-wide link interception to route URLs to your preferred browser.
  • Display Over Other Apps (SYSTEM_ALERT_WINDOW): Enables rendering the floating overlay picker dialog over other applications without switching context.
  • Internet & Network State: Used exclusively when you explicitly view a webpage in the Preview Page or check for app updates. Never used for background data collection.
  • Hardware Permissions (Camera, Microphone, Location): Optional runtime permissions for the Preview Page. Only prompted if a website you deliberately visit requests media or location access and you grant permission. Choose Browser never accesses these sensors on its own.
Updates & Open Source

Direct & Anonymous Update Checks

Choose Browser checks for application updates through direct, read-only HTTPS requests to the official open-source repository manifest. No unique hardware identifiers, advertising IDs, or telemetry payloads are transmitted during update checks.

Free, Open-Source & Fully Auditable

Choose Browser is published as open-source software under the Apache License 2.0. The complete source code, build scripts, and cryptographic release signatures are available publicly for independent security review and audit.
